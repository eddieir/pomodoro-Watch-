# Tomato Watch

A calm, mobile-first Pomodoro timer designed for gentle, intentional focus.

## Features

- Focus, soft-break, and long-break modes
- Editable session durations and daily goal
- Automatic long break cadence
- Daily focus session and minute tracking
- Editable “attention” note for the current study topic
- Between-session ritual checklist
- Completion sound, vibration, and browser notifications
- Evening mode
- Local persistence — no account or backend required
- Installable PWA with offline support
- Netlify-ready static deployment

## Local preview

Serve the repository with any static server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Netlify

The included `netlify.toml` publishes the repository root directly. No build command or environment variables are required.
